# YouTube Metadata Generation Rules (Strict Specification)

이 문서는 유튜브 영상의 **제목 및 설명란 메타데이터 작성 규약(SSOT)**을 정의합니다.
어떠한 경우에도 임의의 문장형 설명 추가, 카테고리 명칭 변경, 이모지 삽입, 템플릿 변형을 엄격히 금지합니다.

---

## 1. 유튜브 제목 표준 형식
```text
{floor}층 {grade}등급 {display_name} 실전 공략 가이드 [브리미르]
```
- **금지 사항**:
  - 이모지(🔥, ⚔️, 🛡️ 등) 사용 금지
  - 임의의 수식어("초보자 필독", "충격적인 패턴" 등) 금지

---

## 2. 유튜브 설명란 표준 템플릿 (사령군주 레퍼런스 엄수)
```text
브리미르 {floor}층 {grade}등급 보스 '{display_name}' 실전 스킬 대응 분류표입니다.

[실전 패턴 대응 가이드]

1. cc기로 끊거나 교전컨트롤로 회피해야됨
- {인게임 텔레그래프 스킬명}
- {인게임 텔레그래프 스킬명}

2. 패링
- {인게임 텔레그래프 스킬명}
- {인게임 텔레그래프 스킬명}

3. cc기로 무조건 끊기
- {인게임 텔레그래프 스킬명}
- {인게임 텔레그래프 스킬명}

자세한 룬·몬스터 정보는 검색창에 '브리미르 버스터즈'를 검색하세요.
게임은 스팀(Steam)에서 『브리미르: 순례자의 탑』을 검색하면 확인하실 수 있습니다.

#브리미르 #{공백없는보스이름} #{영문카멜케이스보스이름} #Brimir
```

---

## 3. 핵심 구조적 제약 사항 (Non-Negotiable)

1. **Zero-Explanation Rule (설명형 서술 절대 금지)**:
   - 불릿(`- `) 뒤에는 **오직 인게임 스킬명/텔레그래프명**만 위치해야 합니다.
   - ❌ 절대 금지: `- 뼈 브레스: 부채꼴 범위로 뼈를 뿜어내니 뒤로 물러서세요.`
   - ❌ 절대 금지: `- 석화 응시! (게이지 찰 때 패링 타이밍 맞추기)`
   - ✅ 올바른 형태: `- 뼈 브레스`, `- 석화 응시!`

2. **3단 분류 카테고리 명칭 고정**:
   - `1. cc기로 끊거나 교전컨트롤로 회피해야됨`
   - `2. 패링`
   - `3. cc기로 무조건 끊기`
   - 위 3개 번호와 텍스트를 토씨 하나 변경하지 마십시오.

3. **인게임 텔레그래프 원본 충실도**:
   - 인게임 텔레그래프에 느낌표(`!`)가 있으면 반드시 느낌표를 유지하십시오. (예: `석화 응시!`, `원한의 손톱!`, `철옹성!`)
   - 인게임 데이터베이스(`enemy_telegraph.gd`, `enemy_boss_ai.gd`, `monsters.json`, `skills.json`)에 등록된 공식 명칭만 사용합니다.

4. **하단 푸터 및 해시태그 고정**:
   - `자세한 룬·몬스터 정보는 검색창에 '브리미르 버스터즈'를 검색하세요.`
   - `게임은 스팀(Steam)에서 『브리미르: 순례자의 탑』을 검색하면 확인하실 수 있습니다.`
   - 해시태그 4개 고정: `#브리미르 #{보스명} #{영문보스명} #Brimir`

---

## 4. 자동 생성 및 검증 도구
수동 작성 시 발생할 수 있는 휴먼 에러 및 환각(Hallucination)을 방지하기 위해 다음 CLI 도구를 반드시 사용하거나 검증을 거치십시오:
```bash
python tools/generate_youtube_meta.py "{보스이름}"
```
